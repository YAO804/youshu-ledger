# 有数记账

两个人的记账小程序。**打开即用：不用注册、不用登录、不用验证码、不用选模式。**

远程：`https://github.com/YAO804/youshu-ledger.git`

## 怎么用

打开就是**统计概览页**，本月花了多少、收了多少、钱花在哪些分类，一屏看完。点「记一笔」→ 选分类 / 账户 → 保存。内置「默认账户」和 15 个收支分类，不用先做任何配置。

- **云端共享**（默认）：账目存在云端，**两个人打开就是同一本账**，实时共享。
- **本机账本**：账目只存在这台手机上，云服务坏了也能记账。
- 两者可在「我的 → 数据存储方式」手动切换，选择会记住；切云端前会先探测，探不通就拒绝切换并说明原因。

> **共享账本没有鉴权**：这是刻意做的简化，代价是任何能打开这个小程序的人都能读写账目。只适合两个人私密使用，别把预览码或小程序随意外发。如果以后需要隔离，再加一层口令/账号即可。

## 功能

- **概览（首页）**：一张顶部概览卡（月份切换 + 本月结余 + 收入 / 支出 + 结余率 / 日均支出 / 最大支出分类 / 笔数四指标一行内联），支出分类构成（100% 堆叠条 + 单行图例：金额 / 占比 / 笔数），近 6 个月收支柱状趋势，账户余额、预算进度、最近账目
- **记一笔**：支出 / 收入、金额、分类、支付账户、日期、备注
- **统计**：每次进入默认当前的月份；一年的收支趋势（横向可拖动，点柱子切到该月）、全部分类占比、预算进度
- **分类明细**：点概览或统计里的分类行，看该分类当月的全部流水、合计与占比；排序拆成「依据（时间/金额）× 方向（正序/倒序）」两个分段控件，长按可删除单条
- **我的**：昵称、账目总数、设置入口、清空数据（二次确认）
- **管理页**：支付账户与余额、分类管理、预算设置、周期记账、CSV 导入导出
- **附加能力**：预算与超支提醒、周期记账（启动懒触发 + 幂等）、CSV 账单导入、CSV 导出与分享

### 首页概览的设计依据

参考 GitHub 上主流开源记账项目的 Dashboard 约定（FinTrack、miyu0201/personal-finance-tracker、NHasan143/monthly-expenses-tracker 等）：**首屏给财务健康度概览**——指标卡、分类构成、趋势、最近记录，并对空数据做安全处理。落到本项目：

- **聚合后置**：`getDashboard(month)` 在数据层一次算完所有派生指标（结余率、日均、Top5、堆叠占比），页面只渲染格式化结果，不塞原始记录进视图层。
- **不引图表库**：ECharts for WeChat 约 180KB+，wx-charts 约 32KB 且要处理 Canvas/Retina 兼容；两人用的小程序数据量小，继续用纯 WXML/WXSS 的堆叠条和柱状图，零依赖、包体积只增约 8KB。
- **颜色编码分类**：Top5 固定配色，与堆叠条、条形图、图例一致，便于快速识别最大支出。
- **顶部只留一个视觉块**：月份切换、结余、收支、四个指标原先分散在「月份卡 + 结余卡 + 2×2 指标方块」三块里，加起来约 766rpx，把支出构成顶到首屏之外。现在合成一张概览卡、指标改成 4 列内联一行，顶部压到约 424rpx，首屏就能看到支出构成。
- **空态安全**：没有任何账目时仍能正常渲染指标条与占位文案，不崩、不出现 `NaN`；加载中 / 出错时顶部只留月份切换，不闪出 `¥ 0.00` 的假数字。
- **可切换月份 / 展开全部流水**：概览默认只显示最近 5 笔，避免首屏过长；月份切换沿用原明细页交互，只是嵌到概览卡顶部。

## 架构

| 位置 | 职责 |
| --- | --- |
| `utils/ledger-store.js` | 唯一数据访问门面，接口统一 `async` + `{ data, error }`；按当前存储方式选实现，另提供 `setMode()` / `mode` / `notice` 与 `getDashboard(month)` 聚合首页概览 |
| `utils/dashboard.js` | 概览派生指标的纯函数（结余率 / 日均 / Top5 / 堆叠占比 / 最近记录），不依赖 `wx` 与云 API，可单测 |
| `utils/ledger-store.cloud.js` | 共享账本实现，`createTableAccess` + `cloud.database`，**无任何登录态检查** |
| `utils/ledger-store.local.js` | 云服务不可用时的本机兜底实现 |
| `utils/cloud.js` | 唯一 SDK 客户端；`require` 失败或能力残缺时安全降级，不阻塞启动 |
| `utils/workbuddy-data-access.js` / `workbuddy-cloud-diagnostics.js` | 单表 CRUD 封装 / 云请求失败诊断 |
| `app.js` | `ensureReady()` 做首次种子初始化与周期记账懒触发 |

匿名请求的 `auth.uid()` 恒为同一个值，配合 `owner_id DEFAULT auth.uid()` 的 RLS，两个人天然读写同一份数据，因此**不需要账号体系**。`utils/cloud.js` 只使用 `publicConfig` 的三个公开值，服务端密钥不下发，前端不发送 `owner_id`。

### 数据表（public，全部启用 RLS）

| 表 | 用途 |
| --- | --- |
| `ledger_accounts` | 支付账户与初始余额 |
| `ledger_categories` | 收支分类 |
| `ledger_records` | 账目主表（金额整数分，`source_key` 幂等） |
| `ledger_budgets` | 月度 / 分类预算 |
| `ledger_recurring_rules` | 周期规则 |
| `ledger_profiles` | 昵称 |

每张表 `owner_id TEXT NOT NULL DEFAULT auth.uid()`，单条 `FOR ALL` 策略 `USING / WITH CHECK (owner_id = auth.uid())`。`ledger_records` 上有 `(owner_id, source_key)` 部分唯一索引，兜住周期记账与 CSV 重复导入。

### 设计约定

- 金额一律**整数分**（`BIGINT`），显示时由 `utils/format.js` 转换。
- 账户不存可变余额：`余额 = 初始余额 + Σ收入 − Σ支出`，编辑或删除账目不会导致漂移。
- 周期记账在 `ensureReady()` 里按 `nextRunAt` 补生成，用 `ruleId:date` 做幂等；日期上限 28 日。
- CSV 导入支持标准列名（日期/时间、金额，可选收支、分类、账户、备注）。微信、支付宝账单多为 GBK，需先另存为 **UTF-8**，否则中文乱码。

## 两种存储方式与切换

「我的 → 数据存储方式」有两段切换：**本机账本 / 云端共享**。选择写在本机 `youshu_storage_mode`，下次启动沿用。

判定顺序：

1. 存过 `local` → 一律用本机，**不会再自动切回云端**。
2. 没存过或存的 `cloud` → 云组件能加载就用云端，否则退回本机并在页面上说明原因。
3. 已选云端但运行中请求失败（`request:fail` / 域名未授权 / 超时）→ 本次运行降级到本机并显示橙色提示条；**不写入偏好**，下次启动仍会重试云端。

切到云端不是改个变量：`setMode('cloud')` 会先跑一次 `shared.init()` 作为探测，只有真的拿到数据才提交切换并落库偏好；探测失败就原样返回错误，页面弹「无法切换到云端模式」并说明只能用本机。这样用户不会停在一个永远报错的模式里。

**两本账互不通**：切模式不会迁移数据、不会删除另一边的数据。要把本机账搬到云端，先「数据导出」拿 CSV，切到云端后再「账单导入」。

### 一键生成测试样例数据

「我的 → 账单导入 / 数据导出 → 测试样例数据 → 生成样例数据」，会先清空当前账本（本机或共享云端），再写入一份固定形态的数据。实现在 `utils/sample-data.js`，写入全部走数据层正常接口，云端与本机模式都能用。

覆盖的场景：

| 维度 | 覆盖 |
| --- | --- |
| 时间 | 近 7 个月，其中 1 个月**故意留空**（验证零数据月份）；统计页趋势窗口是一年，这 7 个月都在窗口内，更早的月份是空桩 |
| 结余 | 正常正结余、**负结余**（标红）、**收支刚好打平** |
| 预算 | 本月总预算超支、餐饮分类预算超支、上月总预算未超支 |
| 分类 | 全部预置分类 + 自定义「宠物 / 旅行 / 红包」，其中「旅行」零流水零预算 |
| 金额 | 0.01 元、9.90 元、带千分位的 1,299.00、3200 元房租 |
| 备注 | 空、含逗号、含换行、超长中文 |
| 账户 | 信用卡负余额、有初始余额但无流水的储蓄卡、默认账户 |
| 周期规则 | 一条启用（房租）、一条停用（视频会员），不立刻生成账目 |

记录日期用「相对当前月的偏移」表达，几个月后再点也不会全部落到窗口之外。重复点击会先清空再写入，不会叠加。

### 云端连不上怎么办

本期新增自动降级：只要云端请求返回 `request:fail`（最常见是 `url not in domain list`），本次运行内直接切到本机账本，首页顶部显示一条橙色提示，记账、统计、导出都照常可用，不会白屏或每页弹错。

但真机要真正连上共享账本，`mp-api.app.workbuddy.host` 必须在小程序后台登记为 request 合法域名：

1. 打开 `mp.weixin.qq.com` → 开发管理 → 开发设置 → 服务器域名；
2. 在 **request 合法域名** 中添加 `https://mp-api.app.workbuddy.host`；
3. 保存后重新扫预览码（域名生效有几秒到几分钟延迟）。

开发者工具模拟器不受白名单限制，只要在「详情 → 本地设置」勾上「不校验合法域名」即可（本机已写进 `project.private.config.json`）。

### 已知边界

- 匿名 REST 写入会落到 `owner_id = 'anon'`，这正是共享账本的机制；代价是所有匿名访问者共享同一命名空间，没有鉴权。
- 「生成样例数据」会**先清空账本**（共享模式下两个人一起清），只在调试时点。
- 降级到本机账本后，两台手机各存各的，不会互相同步，也不会自动补传到云端。
- 两种模式的数据**互不迁移**，切换后看到的是另一本账，需要手动导出 CSV 再导入。
- **真机 / 体验版、两台设备同时读写的一致性、CSV 导出分享、账单文件导入，仍需手机扫预览码验证**。
- 本机兜底模式下清缓存 / 卸载会丢数据，建议用 CSV 定期备份。
- 当前是极简共享账本，没有成员、权限、邀请流程。
